# 이것은 ClassM 프로그램을 사용하는 학교에서 ClassM을 차단할 수 있는 프로그램입니다.

---

# 코드 설명
* `@echo off` -> CMD 창에서 실행되는 명령어 텍스트를 화면에 출력하지 않도록 설정합니다. (화면을 깔끔하게 유지하고 불필요한 리소스 소모를 방지)
* `:loop` -> 다시 돌아올 반복문(루프)의 기준점(레이블)을 지정합니다.
* `taskkill /f /im ClassM_Client.exe >nul 2>&1` -> `ClassM_Client.exe` 프로그램을 강제로 종료하고, 이미 종료되었거나 프로그램이 없을 때 발생하는 오류 메시지를 화면에 표시하지 않고 숨깁니다.
  * `taskkill`: 프로세스를 종료하는 명령어
  * `/f`: 프로세스를 강제(Force) 종료
  * `/im`: 종료할 프로세스의 이미지 이름(Image Name) 지정
  * `>nul 2>&1`: 출력되는 성공/오류 메시지를 모두 차단
* `goto loop` -> 지정한 `:loop` 기준점으로 되돌아가 코드를 무한 반복시킵니다.
